## 2. Tools to Develop (with Robust Prompts)

### A. JSON Tools
#### 1. JSONLint, JSON Formatter, Viewer
- **Prompt:**  
  Develop a tool that allows users to paste/upload JSON, instantly format/beautify, validate, and visualize it as a collapsible tree. Add features for error highlighting, minify, copy, download, and share.  
  **Extra:** Support large files, dark mode, and "Explain this JSON" (AI-powered summary).  
  **SEO:** Free Online JSON Formatter, Validator & Viewer – Beautify, Validate, Visualize JSON Instantly

#### 2. TableConvert, CDKM, Aconvert (JSON ↔ Excel/CSV)
- **Prompt:**  
  Build a converter for JSON ↔ CSV/XLSX. Users can paste/upload JSON or CSV/XLSX, preview as a table, and convert both ways.  
  **Extra:** Support batch conversion, download as file, copy to clipboard, and "AI Table Insights" (summarize table, find anomalies).  
  **SEO:** Convert JSON to Excel, CSV, and vice versa – Fast, Free, Secure Table Converter

### B. AI Image Tools
#### 3. AI Background Remover
- **Prompt:**  
  Create an AI-powered tool to remove backgrounds from images (PNG/JPG), with preview, download, and batch processing.  
  **Extra:** Add "Magic Brush" for manual touch-up, background color/replace, and before/after slider.  
  **SEO:** Remove Image Background Online – Free AI Background Remover

#### 4. Image Enhancer (Upscale, Unblur, Restore, Colorize)
- **Prompt:**  
  Develop a tool to enhance images using AI: upscale, unblur, colorize, and restore old photos.  
  **Extra:** Batch processing, side-by-side comparison, and "AI Art Style Transfer".  
  **SEO:** AI Image Enhancer – Upscale, Unblur, Restore, and Colorize Photos Online

### C. OCR & File Tools

## 3. Development Strategy

- **Follow your current codebase structure:**  
  - Each tool in its own folder under `app/(tools)/[tool-name]/` with `page.tsx`, `layout.tsx`, `seo-content.tsx`
  - Register in `lib/tools-data.ts` with robust SEO metadata
  - Use your existing UI components for consistency (Card, Badge, Input, etc.)
  - Add extra, out-of-the-box features for engagement (AI, batch, analytics, sharing, etc.)
  - Ensure all tools are mobile-friendly, fast, and privacy-first (local processing where possible)
  - Write comprehensive, humanized SEO content for each tool

- **Design/UX:**  
  - Use gradients, icons, and cards matching your current theme
  - Add onboarding tips, tooltips, and "Did you know?" facts
  - Include "Share this tool" and "Feedback" options

- **SEO:**  
  - Each tool should have a unique, keyword-rich meta title, description, and FAQ
  - Add schema.org structured data for tools, FAQs, and reviews
  - Add Humanize Content to the tool page
